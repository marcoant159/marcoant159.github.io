# marcoant159.github.io

## 🔗 Página de Bio Links do Instagram

Este é o seu site de bio links pessoal, hospedado no GitHub Pages!

### 🌐 Acesse sua página

Após fazer commit das suas alterações, sua página estará disponível em:
**https://marcoant159.github.io**

### ✏️ Como personalizar

#### 1. Adicionar sua foto de perfil
- Coloque sua imagem na pasta `images/`
- Renomeie para `profile.jpg` (ou atualize o nome no `index.html`)
- Veja instruções detalhadas em `images/README.md`

#### 2. Editar suas informações
Abra o arquivo `index.html` e personalize:
- **Nome**: Mude "Marco Antonio" para seu nome
- **Bio**: Altere "Bem-vindo ao meu perfil! 🚀" para sua descrição
- **Links**: Atualize os URLs dos links sociais (Instagram, WhatsApp, etc.)

#### 3. Adicionar mais links
No arquivo `index.html`, copie e cole este código dentro da div `class="links"`:

```html
<a href="https://seu-link-aqui.com" class="link-button" target="_blank">
    <span class="icon">🔗</span>
    Nome do Link
</a>
```

#### 4. Mudar as cores
Edite o arquivo `style.css` para personalizar:
- **Gradiente de fundo**: Linha 11 - `background: linear-gradient(...)`
- **Cor dos botões**: Linhas 88-92
- **Cor da borda da foto**: Linha 49

### 📱 Recursos
- ✅ Design responsivo (funciona em celular e desktop)
- ✅ Animações suaves
- ✅ Efeitos hover nos botões
- ✅ Totalmente personalizável

### 🚀 Como fazer upload das alterações

1. **Via navegador (GitHub.com)**:
   - Clique no arquivo que quer editar
   - Clique no ícone de lápis (Edit)
   - Faça suas alterações
   - Clique em "Commit changes"

2. **Via Git (linha de comando)**:
   ```bash
   git add .
   git commit -m "Atualiza informações do perfil"
   git push
   ```

Aguarde alguns minutos para as alterações aparecerem no site!
